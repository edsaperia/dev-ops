# owner/ — <owner's name>'s part of dev-ops

This folder is <owner's name>'s: their profile, page, projects, register and improvement log. The rest of dev-ops is the kit, written for any owner; it points here by path. **If you are setting dev-ops up for someone else, delete this whole folder and create theirs from `template/owner/`** (see README.md, *Setting up for yourself*).

- `PROFILE.md` — who the owner is and how they like to be worked with. Every agent reads it first.
- `PAGE.md` — their questions page's link and id, the environment's values, the daily review's schedule.
- `projects.md` — the projects that use dev-ops, and what is particular to each.
- `REGISTER.md` — dev-ops work left undone, each with its condition to act.
- `IMPROVEMENT-LOG.md` — the daily improvement review's numbers, friction and changes.
