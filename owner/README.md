# owner/ — Ed Saperia's part of dev-ops

This folder is Ed Saperia's: his profile, page, projects, register and improvement log. **If you are setting dev-ops up for someone else, delete this whole folder and create theirs from [`template/owner/`](../template/owner/)** (see [README.md, *Setting up for yourself*](../README.md#setting-up-for-yourself)).

- [`PROFILE.md`](PROFILE.md) — who the owner is and how he likes to be worked with. Every agent reads it first ([`AGENTS.md`](../AGENTS.md)).
- [`PAGE.md`](PAGE.md) — his questions page's link and id, the environment's values, the daily review's schedule.
- [`projects.md`](projects.md) — the projects that use dev-ops, and what is particular to each.
- [`REGISTER.md`](REGISTER.md) — dev-ops work left undone, each with its condition to act.
- [`IMPROVEMENT-LOG.md`](IMPROVEMENT-LOG.md) — the daily improvement review's numbers, friction and changes.
- [`local/windows.md`](local/windows.md) — traps on his Windows laptop.
- [`q/index.html`](q/index.html) — a forwarding page to his questions page.
